# 2DIP-AS91896-91897
Github repository for the NCEA level 2 DIP AS91896 and AS91897 internals.

# To do list

This application is a python based to-do list where users can create, update and track tasks.

---

# How to set up and run the program

1. Install the following external modules if not installed already:
- tkinter
- tkcalendar

2. Run the main file using 'python -m main' (so the main can find imported modules)
